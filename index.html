Política de Privacidad de Tronos

Última actualización: 21 de septiembre de 2026

Esta Política de Privacidad describe el tratamiento de información relacionado con la aplicación móvil Tronos, identificada con el paquete com.tronos.app.

1. Acerca de Tronos

Tronos es una aplicación que permite realizar búsquedas y acceder a sitios web mediante un navegador integrado. Su objetivo es facilitar la navegación y ayudar al usuario a consultar sitios web desde una interfaz sencilla.

2. Información y navegación

Tronos permite al usuario introducir búsquedas, direcciones web y acceder a contenido disponible en Internet.

Los sitios web visitados pueden aplicar sus propias políticas de privacidad, utilizar cookies u otras tecnologías y recopilar información de acuerdo con sus propios términos.

Tronos no controla las prácticas de privacidad de los sitios web externos. Se recomienda consultar la política de privacidad de cada sitio visitado.

3. Datos personales

Tronos no requiere actualmente que el usuario cree una cuenta para utilizar las funciones básicas de navegación.

La información que el usuario introduzca en páginas o servicios externos durante la navegación puede ser transmitida directamente a los sitios web o servicios que el propio usuario decida utilizar.

4. Servicios de terceros

Tronos puede utilizar componentes y servicios proporcionados por Android, Google y otros proveedores necesarios para el funcionamiento de la aplicación.

Estos servicios pueden tratar determinada información técnica de acuerdo con sus propias políticas de privacidad.

5. Compras y suscripciones

En caso de que Tronos ofrezca compras o suscripciones mediante Google Play, las operaciones de pago serán procesadas por Google Play. Tronos no almacena directamente los datos completos de las tarjetas bancarias utilizadas para realizar dichas operaciones.

6. Seguridad

Se adoptan medidas razonables para proteger la información tratada directamente por la aplicación. Sin embargo, ninguna transmisión de información a través de Internet puede garantizarse como completamente segura.

7. Conservación y eliminación de datos

Tronos no mantiene actualmente cuentas de usuario propias. Cuando se incorporen nuevas funciones que impliquen almacenamiento de datos personales, esta política podrá ser actualizada para explicar los periodos de conservación y los mecanismos disponibles para solicitar su eliminación.

8. Privacidad de menores

Tronos no está diseñada específicamente para recopilar información personal de menores. El acceso a sitios web externos queda sujeto a las condiciones y políticas establecidas por dichos sitios.

9. Cambios a esta Política de Privacidad

Esta Política de Privacidad podrá actualizarse cuando se incorporen nuevas funciones, servicios o requisitos legales. La fecha de la última actualización aparecerá al inicio de este documento.
